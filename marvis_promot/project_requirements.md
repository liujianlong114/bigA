# BigA 模拟盘项目 — 需求总结与补充

## 一、项目定位

BigA 是一个面向大 A 股的 AI 驱动模拟交易系统。核心目标：

1. 接入真实行情接口，覆盖全市场 5500+ 只股票
2. 提供完整的模拟撮合交易（T+1、涨跌停、真实费率）
3. 提供持仓分析、涨跌推测、大盘解析、异动原因汇总等智能分析能力
4. 提供 AI 可操作接口，让 AI Agent 能自主完成行情查询、下单、复盘

| 功能 | 详情 |

| 数据源 | 新浪财经（主）+ 东方财富（兜底），多级容错 |

## 三、需求补充（待实现）

### 3.1 核心分析能力（用户明确要求）

#### 3.1.1 持仓分析
- [ ] **行业分布分析**：按申万行业分类统计持仓占比，识别过度集中风险
- [ ] **持仓质量评分**：综合 PE/PB/ROE/毛利率等基本面指标对持仓打分
- [ ] **持仓与大盘相关性**：计算持仓组合相对沪深300/中证500的 Beta 值
- [ ] **持仓集中度风险提示**：单票超20%、单行业超40%时预警
- [ ] **持仓历史回测**：按当前持仓模拟过去 N 日走势，评估最大回撤
- [ ] **止盈止损建议**：基于技术指标（均线/布林带/ATR）给出参考价位

#### 3.1.2 涨跌推测
- [ ] **多因子评分模型**：技术面（趋势/动量/波动率）+ 资金面（成交量/换手率/大单流向）综合打分
- [ ] **短期走势预测**：基于 LSTM/Transformer 的时序预测（1日/3日/5日）
- [ ] **形态识别**：头肩顶、双底、三角形突破、锤子线等经典形态自动检测
- [ ] **支撑压力位计算**：基于历史成交密集区自动识别关键价位
- [ ] **相似走势匹配**：从历史 K 线库中匹配最相似形态，输出历史后续走势统计
- [ ] **涨跌概率输出**：综合以上维度给出未来 1/3/5 日涨跌概率和置信区间

#### 3.1.3 大盘解析
- [ ] **主要指数实时监控**：上证指数/深证成指/创业板指/科创50/沪深300/中证500/中证1000
- [ ] **市场宽度指标**：上涨家数/下跌家数/平盘家数、涨跌比、新高新低比
- [ ] **市场情绪指数**：涨停/跌停家数、炸板率、连板高度、成交量能
- [ ] **资金流向**：北向资金实时流向、主力资金净流入、板块资金轮动
- [ ] **大盘分时图**：当日分时走势 + 黄白线 + 成交量分布
- [ ] **大盘估值**：PE/PB 分位数、风险溢价（股债性价比）

#### 3.1.4 原因汇总
- [ ] **异动股票检测**：涨跌幅>阈值 / 成交量突增>N倍 / 换手率异常
- [ ] **异动原因自动归因**：关联新闻/公告/财报/行业政策/龙虎榜
- [ ] **涨跌停原因分析**：连板逻辑分析、板块联动、消息面驱动识别
- [ ] **每日复盘报告**：当日大盘总结 + 涨跌板块排名 + 异动个股汇总 + 明日关注
- [ ] **事件驱动分析**：财报日历、限售解禁、股东增减持、分红送转
